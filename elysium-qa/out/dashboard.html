Method. Frontend score from an anonymous HTTP probe classified into live-app / landing-only / coming-soon / gated / broken. Contract score from code presence, EIP-1967 proxy detection and standard view-call responses. Scenario score from replayed lifecycle steps (simulated with eth_call before any transaction is sent). Components are renormalised when a data source is unavailable, and a project we could not reach is marked "not tested" rather than zero — recon gaps are never reported as project failures. Transaction counts are net of sequencer/batch overhead. Scores measure testability and readiness, not investment merit.

Reproducible. One command, no API keys, no wallet for this run. Raw probe output is included alongside this page.
